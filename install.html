安裝到 iPhone 主畫面（像 App 一樣使用）

💡白話導讀
這套網站已經做成「PWA」（漸進式網頁應用）：有自己的 App 圖示、打開是全螢幕沒有網址列、放在 https 網址上的話離線也能讀。要做到這件事只有兩步：先把網站放到一個 iPhone 連得到的網址，再在 Safari 用「加入主畫面」。

1. 原理（一句話）

iPhone 沒辦法直接打開電腦裡的檔案，所以網站要先放到「網址」上。放上去之後，Safari 的「加入主畫面」會把它變成一個 App 圖示。

2. 三種放上網的方式

方式適合怎麼做離線能用公開嗎
A. 同一個 Wi‑Fi（最快，先試這個）在家、電腦開著在電腦執行 _build/serve_lan.ps1，它會印出一個網址（像 http://192.168.1.23:8765/index.html），iPhone 用 Safari 打開否（電腦關了就不能看）否，只有同一個 Wi‑Fi 看得到
B. GitHub Pages（建議，免費、https）隨時隨地、離線1. 到 github.com 申請帳號 2. 新增一個空的 repository（例如 poker-training，Public） 3. 在電腦執行 _build/deploy_github_pages.ps1 -RepoUrl https://github.com/你的帳號/poker-training.git 4. 到 repo 的 Settings → Pages，Source 選 Deploy from a branch，Branch 選 main、資料夾 /（root），儲存 5. 幾分鐘後網址是 https://你的帳號.github.io/poker-training/是是（任何知道網址的人都能看；教材沒有你的個資）
C. Netlify 或 Cloudflare Pages不想打指令到 app.netlify.com 註冊後，把整個 html 資料夾拖進去，就會給你一個 https 網址是是
⚠️注意
B 和 C 是公開網址。教材內容沒有你的帳號或個資，但如果你介意，就用 A。

3. iPhone 上的步驟

  1. 用 Safari 打開網址（一定要 Safari，Chrome 沒有這個功能）。
  2. 點畫面下方中間的「分享」按鈕（方框加一個向上的箭頭）。
  3. 往下滑，點「加入主畫面」。
  4. 名稱保留「撲克培訓」，點右上角「加入」。
  5. 回到主畫面，會看到一個金色黑桃的圖示。
🎲舉例
用方式 A 時，網址是 http://192.168.1.23:8765/index.html；加入主畫面之後，只要電腦的伺服器還開著、iPhone 在同一個 Wi‑Fi，點圖示就會全螢幕打開教材。

4. 怎麼確認安裝成功

  • 主畫面有金色黑桃圖示，名稱是「撲克培訓」。
  • 點開後沒有 Safari 的網址列，上方狀態列是深色。
  • 如果用的是 https 網址（方式 B 或 C）：開啟飛航模式再打開 App，仍然能讀，代表離線快取有生效。

5. 內容更新後怎麼辦

  1. 在電腦改完原稿，重新執行 python _build/build_html.py。
  2. 方式 A：不用做別的，iPhone 重新打開 App 就是新版。方式 B：再跑一次部署腳本。方式 C：再拖一次資料夾。
  3. iPhone 上打開 App，畫面底部如果出現「有新版本，點一下重新整理」，點它；沒出現就關掉 App 再開一次。

6. Android 手機

Chrome 打開網址 → 右上角選單（三個點）→「加到主畫面」或「安裝應用程式」。其餘相同。

7. 常見問題

問題原因與解法
iPhone 打不開方式 A 的網址兩台裝置不在同一個 Wi‑Fi；或 Windows 防火牆擋住了（第一次執行會跳出詢問，要選「允許」）；或電腦的伺服器已經關閉
「加入主畫面」找不到你用的不是 Safari。請用 Safari 重開網址
圖示打開是一片白網址打錯或伺服器沒開。先在 Safari 確認網址能開
離線打不開方式 A 本來就不能離線。方式 B/C 第一次打開要連線一次讓它下載快取
深淺色想換右上角的太陽／月亮按鈕可以切換，會記住你的選擇
