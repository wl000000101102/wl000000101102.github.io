翻前完整體系（100bb 6-max，含抽水調整）

開池（RFI）

Raise First In，前面沒有人進池時第一個加注。

開池範圍依位置而定：越早的位置越緊，越晚越寬。教材假設你已經會各位置的開池範圍。

範例：UTG 開 17%，BTN 開 45%，這就是「依位置開池」。

翻前

發了兩張底牌、還沒發公共牌之前的下注回合。

翻前是每手牌的第一個決策點。你只看得到自己的兩張牌，決定要棄牌、跟注還是加注。翻前的決策可以整理成「範圍表」照著打。

範例：你在 BTN 拿到 A♠J♠，前面都棄牌，你加注到 2.5bb，這就是翻前的動作。

尺寸（sizing）

下注或加注的金額，通常用「占底池的百分比」或「開池的幾倍」表示。

尺寸不是隨便選的：小尺寸適合高頻率、範圍優勢；大尺寸適合極化、堅果優勢。固定一套尺寸體系，不要每手換。

範例：「c-bet 33%」= 下注底池的三分之一；「3-bet 3 倍」= 開池 2.5bb 時 3-bet 到 7.5bb。

在名詞表查看 →
3-bet

翻前面對開池的再加注。大盲是第一注、開池是第二注、所以再加注是第三注。

3-bet 有兩種理由：價值（你的牌很強，想把底池打大）或詐唬（想讓開池的人棄牌）。做 3-bet 的人叫 3-bettor。

範例：CO 開 2.5bb，你在 BTN 持 QQ 加注到 8bb，這是 3-bet。

在名詞表查看 →
冷跟（cold call）

翻前面對加注，自己之前沒有投過錢，直接跟注。

冷跟在有位置時是好選項（可以用中等牌看翻牌），沒位置時很差。SB 面對開池幾乎不冷跟，BB 因為已投 1bb 所以可以寬。

範例：CO 開池，你在 BTN 持 77 跟注，這是冷跟。

BB（大盲位）

Big Blind，放大盲的位置。翻前最後行動（已投 1bb，所以跟注很便宜），翻後第二個行動。

因為已經投了 1bb，BB 面對加注只要再補一點就能看翻牌，所以防守範圍很寬。但翻後幾乎都沒位置，是長期虧損最多的位置（這是正常的）。

範例：BTN 開 2.5bb，你在 BB 只要再付 1.5bb 就能看翻牌，所以連 T8s、K7s 這類牌都會防守。

在名詞表查看 →
SB（小盲位）

Small Blind，按鈕左邊、要放小盲的位置。翻後第一個行動，是最差的翻後位置。

SB 已經投了半個大盲，但翻後永遠先行動，所以面對開池時建議「3-bet 或棄牌」，不要跟注。

範例：BTN 開池，你在 SB 拿到 KJs，標準是 3-bet 而不是跟注。

在名詞表查看 →
防守

面對對手的加注或下注，用跟注或加注留在這手牌，不棄牌。

防守太少會被對手用任何牌加注剝削；防守太多會用弱牌輸錢。教材給了各情境的防守比例。

範例：BTN 開池，BB「防守 45 到 50%」意思是 BB 有一半左右的起手牌會跟注或 3-bet。

在名詞表查看 →
4-bet

面對 3-bet 的再加注（第四注）。

4-bet 的範圍很窄：價值通常是 QQ+ 和 AK，詐唬用 A5s 到 A2s 這類有阻擋牌的手。尺寸約是 3-bet 的 2.2 到 2.5 倍。

範例：你開 2.5bb，對手 3-bet 到 8bb，你持 AA 4-bet 到 20bb。

在名詞表查看 →
5-bet

面對 4-bet 的再加注。100bb 下幾乎都是全壓。

5-bet 的範圍非常窄（通常 KK+ 和 AK），因為 4-bet 的範圍已經很強。

範例：對手 4-bet 到 20bb，你持 KK 全壓 100bb。

在名詞表查看 →
Squeeze

有人開池、有人跟注之後，你再加注（3-bet）。

因為底池裡已經有兩個人的錢，squeeze 的尺寸要更大（沒位置時 4 倍開池再加每個跟注者 1 倍）。跟注者的範圍通常沒有很強的牌，所以 squeeze 常能直接拿下底池。

範例：CO 開 2.5bb、BTN 跟注，你在 BB 持 AK 加注到 12.5bb。

在名詞表查看 →
Limp（跛入）

翻前只跟注大盲、不加注就進池。做這件事的人叫 limper。

Limp 通常是弱玩家的特徵，因為它既沒有搶盲注、也沒有建立優勢。面對 limper，你用加注（iso-raise）把他孤立出來、拿位置優勢。

範例：一個玩家在 HJ 只跟 1bb 進池，你在 BTN 持 KJo 加注到 4bb，這叫 iso-raise。

在名詞表查看 →
抽水

平台從每個底池抽走的手續費，通常是 5% 並有上限。

抽水是你最大的固定對手。微額的抽水以 bb 計算比高級別更重，所以範圍要更緊、少打邊緣跟注。GTO Wizard 有依抽水結構分開解的範圍。

範例：底池 $2，抽水 5% = $0.10，在 NL2 等於 5bb。

在名詞表查看 →
範圍

一個玩家在某個情境下可能持有的所有起手牌的集合。撲克不是猜一手牌，是對一整組牌做決策。

因為你看不到對手的牌，所以你只能問「他做了這個動作，可能是哪些牌？」這組牌就是範圍。範圍通常用 13×13 的格子表示（對子在對角線、同花在右上、不同花在左下），或用百分比表示（佔所有起手牌組合的比例）。

範例：「BTN 開池 45%」表示按鈕位會加注最強的 45% 起手牌，大約從 AA 到 K5s、Q8s、J8s、T8s、A2o、K9o 這一帶。

在名詞表查看 →
GTO Wizard

線上的 GTO 學習平台：有算好的解可以查（Study）、可以練習（Trainer）、可以上傳手牌看錯誤（Analyzer）。

本教材用它當主要研究與訓練工具。Cash 方案分 Starter、Premium、Elite 三級，功能額度不同。

範例：每天打開 Trainer 練 BTN vs BB 的翻牌 50 手，看自己的分數。

在名詞表查看 →
跟注

付出跟對手下注一樣的金額，繼續留在這手牌。

跟注的依據是底池賠率：你付的錢佔「底池加你付的錢」的比例，必須小於你贏的機率。

範例：對手下注 5bb 進 10bb 底池，你要付 5bb 贏 20bb，需要至少 25% 的勝算才值得跟。

在名詞表查看 →
加注

在別人已經下注之後，把金額提高。

翻前的第一個加注叫開池（RFI），再加注叫 3-bet。翻後面對下注的加注通常叫 raise，check 之後的加注叫 check-raise。

範例：BB 下注 3bb，你持 set 加注到 10bb。

在名詞表查看 →
bb（大盲單位）

以「大盲的倍數」當單位來數籌碼與底池，這樣不同級別可以互相比較。

1bb 等於一個大盲。NL2 的 1bb 是 $0.02，NL25 的 1bb 是 $0.25。100bb 是標準買入；一個 2.5bb 的加注在 NL25 就是 $0.625。

範例：「輸了 3 個買入」在 NL2 是 $6，在 NL25 是 $75，但用 bb 來講都是 300bb。

在名詞表查看 →
UTG

Under the Gun，6-max 第一個行動的位置（大盲左邊）。最差的位置，開池範圍最緊。

UTG 後面還有五個人可能持強牌，所以只能用最強的 17 到 19% 起手牌開池。

範例：UTG 拿到 A9o，標準是棄牌；同樣的牌在 BTN 就會開池。

在名詞表查看 →
HJ

Hijack，UTG 之後、CO 之前的位置。開池範圍約 20 到 22%。

HJ 後面還有四個人，所以仍然偏緊。有些軟體把 6-max 的第二個位置叫 MP。

範例：HJ 拿到 KTs 可以開池；拿到 K9s 通常棄牌。

在名詞表查看 →
CO

Cutoff，按鈕右邊的位置。開池範圍約 26 到 28%。

CO 只剩按鈕一個人在你後面有位置，所以可以開得比較寬，但要小心被 BTN 3-bet。

範例：CO 開池後被 BTN 3-bet，你在翻後會是沒位置的一方。

在名詞表查看 →
BTN（按鈕位）

Button，發牌鈕所在的位置。翻後永遠最後行動，是最好的位置。開池範圍最寬，約 42 到 45%。

BTN 是整桌最賺錢的位置：翻前只剩兩個盲位在後面，翻後每一條街都是最後行動。本教材最重要的 spot 很多都是 BTN 相關。

範例：BTN 拿到 K5s、Q8s、J8s 這類牌都會開池，因為位置好。

在名詞表查看 →
魚

打得很差的休閒玩家。他們是利潤的來源。

魚的特徵：VPIP 很高、常 limp、常跟注、不太詐唬、攤牌亮弱牌。對魚的策略是多價值、少詐唬、尊重他們的加注。

範例：一個 55/10 的玩家在 HJ limp，你 BTN 用 KJo iso 到 4bb。

在名詞表查看 →
棄牌

放棄這手牌，不再投入任何籌碼，也不能贏底池。

棄牌是撲克最常用的動作。好玩家棄牌的次數遠比跟注多。棄掉的錢不是你的，不要為了「已經投了很多」而繼續。

範例：你持 AJo 在 UTG 面對 3-bet，棄牌是標準動作。

在名詞表查看 →
IP（有位置）

In Position，翻後比對手晚行動。

有位置的人在每條街都看到對手的動作後才決定，可以用更多牌、更便宜地看牌。本教材中 IP 的策略通常比 OOP 更積極。

範例：BTN 對 BB 永遠是 IP。CO 對 BTN 則是 OOP。

在名詞表查看 →
OOP（沒位置）

Out of Position，翻後比對手早行動。

沒位置的人必須先決定，資訊少、更難實現手牌的價值。所以 OOP 要更常 check、範圍要更緊。

範例：SB 3-bet 之後 BTN 跟注，翻後 SB 是 OOP，每條街都要先動作。

在名詞表查看 →
EV（期望值）

Expected Value，一個決策長期平均會賺或賠多少。

撲克的目標是做 EV 最高的決策，不是這一手贏。同一個決策做一萬次的平均結果就是 EV。GTO Wizard 的 Trainer 和 Analyzer 都是用 EV 來評分。

範例：一個跟注 60% 贏 10bb、40% 輸 5bb，EV = 0.6×10 − 0.4×5 = +4bb。

在名詞表查看 →
全壓（all-in）

把所有籌碼一次推進底池。

全壓之後你不用再做任何決定，剩下的牌會直接發完比大小。100bb 的 5-bet 幾乎都是全壓。

範例：對手 4-bet，你持 KK 全壓。

在名詞表查看 →
Iso-raise（孤立加注）

面對 limper 時加注，目的是只剩你和這個弱玩家兩個人打，而且你有位置。

尺寸比一般開池大（3bb 加每個 limper 1bb；盲位再加 1bb）。對魚的 iso 要偏「價值」，因為他們常常跟注。

範例：一個 limper，你在 CO 加注到 4bb；在 SB 則加注到 5bb。

在名詞表查看 →
盲位

SB 和 BB 兩個位置的合稱。

盲位已經投了錢，所以翻前有折扣；但翻後都沒位置，所以是長期虧錢的位置。目標是「少輸」，不是「贏」。

範例：一個 5 bb/100 的贏家，在 BB 可能是 −30 bb/100，這是正常的。

在名詞表查看 →
線性（linear）

一種範圍結構：從最強的牌往下排，中間沒有跳過的牌。

線性 3-bet 範圍像是 QQ+、AK、AQs、JJ、TT、AJs 這樣一路往下。適合對手範圍寬、會跟注、或你沒位置不能冷跟的時候。

範例：SB 面對 BTN 開池用線性 3-bet：最強的 13 到 15% 都 3-bet，其餘棄牌。

在名詞表查看 →
極化（polarized）

一種範圍結構：只有很強的牌和詐唬，中間的牌不在裡面。

翻前極化 3-bet 的中間牌（99、AQo、KQs）會改成冷跟。河牌下注範圍幾乎都是極化的：要嘛價值、要嘛詐唬。

範例：BTN 面對 CO 開池：QQ+/AK 3-bet（價值）、A5s–A2s 3-bet（詐唬）、99 和 AJs 冷跟（中間）。

在名詞表查看 →
價值下注

你認為自己領先，下注的目的是讓更差的牌跟注付錢。

價值下注的檢驗標準：更差的牌會跟注的機率超過一半嗎？會就下注。對愛跟注的對手可以用更弱的牌價值下注（薄價值）。

範例：河牌你持 TPTK，對手是跟注站，你下注 75% 底池，他用中對跟注。

在名詞表查看 →
阻擋牌（blocker）

你手上的牌讓對手持有某些組合的機率下降。

每張牌只有四張。你持 A，對手拿 AA 的組合就從 6 組變 3 組。詐唬時選「阻擋對手強牌」的手；抓詐唬時選「不阻擋對手詐唬」的手。

範例：A5s 是 3-bet 詐唬首選，因為手上的 A 阻擋了對手的 AA、AK、AQ。

在名詞表查看 →
詐唬

用比對手差的牌下注，目的是讓他棄牌。

詐唬要成功需要對手棄牌的機率超過 alpha（下注 ÷ 底池加下注）。微額對手棄牌太少，所以詐唬要少、要挑對象。

範例：河牌你的同花沒中，底池 10bb，你下注 7bb，需要對手棄牌超過 41% 才划算。

在名詞表查看 →
可玩性

一手牌在翻後容易不容易打：能不能做順子、同花、或容易判斷自己領先。

同花連牌可玩性高（能中很多種好牌），不同花的斷張（K7o）可玩性低（中了一對也不知道自己好不好）。

範例：A5s 和 K7o 翻前勝率差不多，但 A5s 可玩性高很多，所以能用來 3-bet、冷跟。

在名詞表查看 →
堅果（nuts）

目前公共牌下，可能的最大牌。

「接近堅果」指只輸給極少數組合的牌。河牌超池通常只用堅果或接近堅果的牌做價值。

範例：牌面 K♠7♠2♠J♦3♣，堅果是 A♠ 配任何黑桃的同花。

在名詞表查看 →
同花

五張同一花色的牌。

同花比順子大。翻牌三張同花色（單色牌面）時任何人都可能已經有同花，所以一對的價值大幅下降。

範例：翻牌 K♠7♠2♠，你持 A♠5♠，你有同花。

在名詞表查看 →
順子

五張連號的牌（花色不限）。

順子常出現在連接的牌面（876、T98）。有順子可能的牌面要小心，這也是教材說「中張連接牌面對跟注者有利」的原因。

範例：翻牌 876，你持 T9，你有順子（6 到 T）。

在名詞表查看 →
X 高（A 高、K 高）

講牌面時：公共牌最大的是 X。講手牌時：沒成對，最大的牌是 X。

「A 高牌面」= 翻牌最大的牌是 A。「A 高」的手牌 = 你沒有對子，最大的牌是 A，有時能在攤牌贏過更小的高牌。

範例：翻牌 A72 是 A 高牌面；你持 AQ 在 972 的牌面是「A 高」的手牌。

在名詞表查看 →
位置

你在這一手牌的行動順序。越晚行動越有利，因為你看到別人的動作後才決定。

每手牌按鈕順時針移一格，所以每個人輪流坐到好位置和壞位置。翻後的行動順序固定從小盲開始、按鈕最後。位置是撲克最重要的結構性優勢。

範例：你在 BTN，對手在 BB。翻牌後他要先動作，你看了他 check 之後再決定要不要下注。

在名詞表查看 →
起手牌（底牌）

發給你、只有你看得到的兩張牌。

德州撲克總共有 1,326 種兩張牌的組合，整理後是 169 種不同的起手牌（13 個對子、78 種同花、78 種不同花）。

範例：A♠K♠ 是一種起手牌，它屬於 AKs。

在名詞表查看 →
同花高張

兩張都是高張且同花色，例如 K♠Q♠、Q♥J♥。

同花高張同時有「做大對」和「做同花、大順子」的能力，是最常被拿來冷跟和 3-bet 的牌之一。

範例：KQs、KJs、QJs、JTs、ATs 都是同花高張。

在名詞表查看 →
同花連牌

同花色且數字相連的兩張牌，例如 8♠7♠。

同花連牌可以做順子也可以做同花，可玩性高，但單獨拿到一對時很弱。適合在有位置、底池會很大的時候玩。

範例：T9s、98s、87s、76s、65s 都是同花連牌。

在名詞表查看 →
底池

這一手牌裡所有人已經投進去的錢的總和。

底池是你在爭的東西。下注尺寸常用「占底池的百分比」表示，例如「下注 50% 底池」就是下注金額等於底池的一半。

範例：底池 10bb，你下注 5bb，就是下注 50% 底池；對手跟注後底池變成 20bb。

在名詞表查看 →
翻牌

翻前下注結束後，一次發出的三張公共牌，以及接下來的下注回合。

翻牌是資訊最多的一條街：三張牌一起出來，決定了誰的範圍比較強。教材花最多篇幅講翻牌，因為大多數底池在這裡決定方向。

範例：翻牌 K♠7♦2♣，你持 A♠K♥ 就有了「頂對」。

口袋對

兩張底牌是同一個數字，例如 77。

口袋對翻牌中 set（三條）的機率約 12%（大約八次一次）。小口袋對的價值主要就是中 set 贏大底池。

範例：你持 5♠5♥，翻牌 K♦5♣2♠，你中了 set。

在名詞表查看 →
手牌表示法（AKs、AKo、22+、A2s+）

s = 同花（suited），o = 不同花（offsuit），+ = 這個以上都算。

AKs 是同花的 A 和 K，AKo 是不同花。22+ 是所有口袋對。A2s+ 是所有同花的 A 配任何牌。KTs+ 是 KTs、KJs、KQs。T9s 是同花的 T 和 9。

範例：「3-bet 範圍：QQ+、AK、A5s–A2s」意思是 QQ、KK、AA、所有 AK（同花與不同花）、以及同花的 A5、A4、A3、A2。

在名詞表查看 →
權益（equity）

你的牌對上對手的牌（或範圍），把牌全部發完後你贏的機率。

權益不是「現在誰大」，而是「最後誰贏的機率」。聽牌雖然現在沒成牌，但有權益。底池賠率的決策就是在比較權益和要付的錢。

範例：AK 對 QQ 的翻前權益約 44%，意思是發完五張牌 AK 大約 44% 會贏。

在名詞表查看 →
實現權益

你的牌理論上有的勝算，實際上能拿到多少。

有位置、可玩性高的牌容易實現權益；沒位置、要常常面對下注而棄牌的牌實現不了。所以 BB 的防守線不是看原始勝算，而是看能實現多少。

範例：K7o 面對 BTN 開池理論上有 35% 勝算，但沒位置又常棄牌，實際只能實現其中一部分，所以棄牌。

在名詞表查看 →
頂對

你手上有一張牌和公共牌裡最大的那張配成一對。

頂對是翻牌最常見的「好牌」，但不是「大牌」。在單次加注底池裡，頂對通常只值一到兩條街的價值，不值得輸掉全部籌碼。

範例：翻牌 K72，你持 KQ，你有頂對（K）。

在名詞表查看 →
被支配（dominated）

你的牌和對手共用一張大牌，但你的另一張比較小。中了一對也輸。

被支配的牌最危險：你以為中了頂對，其實對手踢腳更大。這是 AJo、KQo 面對 3-bet 要棄牌的原因。

範例：你持 AJ，對手持 AK，翻牌 A72，你們都中頂對，但你輸。

在名詞表查看 →
高張

A、K、Q、J、T 這五種大牌。

兩張高張的起手牌（例如 KQ、QJ）叫「高張牌」，容易做出頂對和大順子，是翻前常玩的牌。

範例：KQs 是「同花高張」，在 BTN 幾乎永遠會開池。

在名詞表查看 →
級別（NL2、NL25…）

NL 是無限注德州撲克，數字是標準買入的美金（等於 100 個大盲）。

NL25 代表盲注 $0.10/$0.25、標準買入 $25。數字越大級別越高，對手平均越強。各級別的盲注：NL2 = $0.01/$0.02，NL5 = $0.02/$0.05，NL10 = $0.05/$0.10，NL25 = $0.10/$0.25，NL50 = $0.25/$0.50，NL100 = $0.50/$1。

範例：你有 $100，在 NL2 等於 50 個買入；在 NL25 只有 4 個買入。

在名詞表查看 →
SPR（籌碼底池比）

Stack-to-Pot Ratio，剩餘籌碼 ÷ 翻牌時的底池。數字越小，用越弱的牌就可以全壓。

SRP 的 SPR 約 17（一對不該全壓），3BP 約 4（超對和 TPTK 常可以全壓），4BP 約 1.5（有對就全壓）。

範例：翻牌底池 20bb，你剩 90bb，SPR = 4.5。

在名詞表查看 →
族群

某個級別上的「平均對手」。族群傾向是大多數對手共同的錯誤。

沒有對特定對手的資料時，用族群傾向當預設剝削。NL25 和更低級別的族群：面對 3-bet 棄太多、河牌詐唬不足、跟注太多。

範例：面對陌生對手的河牌大注，依族群傾向預設多棄一對。

在名詞表查看 →
剝削

針對對手的錯誤，刻意偏離 GTO 來多賺。

剝削的三步：觀察 → 假設他在哪裡偏離 → 往反方向調整。對魚可以大幅偏離，對 reg 要小幅，因為會被反剝削。

範例：對手面對 c-bet 棄 70%，你把 c-bet 頻率從 70% 拉到 100%，這是剝削。

在名詞表查看 →
Set（暗三條）

口袋對配上一張公共牌，形成三條。對手很難看出來。

Set 是 100bb 現金桌最賺錢的牌之一：很強又很隱藏。原則是「不慢玩」，直接建底池。

範例：你持 77，翻牌 K73，你有 set。

在名詞表查看 →
封頂（capped）

一個範圍裡沒有最強的牌，因為如果有，他之前就會加注了。

對手的範圍被封頂時，你可以用超池和更多詐唬攻擊他。你自己 check-call 兩次之後也會被封頂。

範例：BB 翻牌轉牌都只是跟注，他的 set 和兩對大多會加注，所以河牌他的範圍被封頂。

在名詞表查看 →
隱含賠率

除了現在的底池，還算上「中牌之後能再從對手那裡贏多少」。

小口袋對和同花連牌靠隱含賠率賺錢：現在的底池賠率不夠，但中了 set 或同花可以贏對手一大筆。對手籌碼深、愛付錢時隱含賠率才高。

範例：你持 55 面對 3-bet，直接的賠率不夠，但對手 100bb 深又愛跟注，中 set 能贏很多，所以可以跟。

在名詞表查看 →
返水

平台把你付過的抽水按比例退回給你。

返水在微額幾乎等於你勝率的一半，一定要了解平台的返水制度並計入收入。Natural8 的返水計畫叫 Fish Buffet。

範例：你每 100 手付 10bb 抽水，返水 30% 就等於每 100 手多賺 3bb。

在名詞表查看 →
短碼

籌碼少於 60bb 左右的玩家或情境。

短碼的翻前加注常常等於承諾全壓，所以對短碼要用更緊的跟注範圍，不要用「希望中大牌」的牌去跟。

範例：一個 30bb 的對手 3-bet 你，他的 3-bet 幾乎等於全壓，AJ 這種牌直接棄。

在名詞表查看 →
6-max

最多六個人一桌的桌型。

線上現金桌最常見的桌型。人少代表每個人更常拿到好位置、要玩的牌更多，策略比九人桌更積極。

範例：6-max 的六個位置依序是 UTG、HJ、CO、BTN、SB、BB。

在名詞表查看 →
解的複雜度（Simple / General / Complex）

GTO Wizard 的解有不同的下注尺寸數量：Simple 只有一個尺寸，General 幾個，Complex 很多。

新手先用 Simple：先學「要不要下注」，再學「下多少」。太早看 Complex 只會記一堆執行不了的頻率。

範例：Simple 解在翻牌只有 33% 一個尺寸；Complex 解可能有 20%、33%、50%、75%、125% 五種。

混合策略（混合頻率）

同一手牌有時做 A、有時做 B，例如 60% 下注、40% check。

GTO 解裡很多手牌是混合的，目的是不被對手預測。新手不需要精確執行混合頻率：超過 70% 的動作當 100% 做，低於 30% 的當 0%。

範例：解說 K72r 上 QJ 有 55% 下注、45% check，兩個動作 EV 幾乎一樣，你固定選一個也沒問題。

在名詞表查看 →
頻率

某個動作做的比例，例如「c-bet 頻率 70%」= 100 次有 70 次會 c-bet。

頻率是針對整個範圍講的，不是單一手牌。「c-bet 70%」的意思是你的所有手牌加起來有 70% 會下注。

範例：BTN 在 A72r 的 c-bet 頻率 85%，意思是 BTN 幾乎所有的牌都會下注。

在名詞表查看 →
VPIP

Voluntarily Put money In Pot，翻前自願投錢進底池（跟注或加注）的手數比例。衡量一個人玩多鬆。

6-max 的合理值約 23 到 26%。40% 以上通常是魚，17% 以下是 nit。

範例：VPIP 45% 的對手幾乎一半的手牌都玩，範圍很寬很弱。

在名詞表查看 →
PFR

Pre-Flop Raise，翻前加注的手數比例。衡量一個人翻前多主動。

VPIP 和 PFR 的差距代表「只跟不加」的比例。差距 3 到 5 是正常；差距很大（例如 40/10）是跟注站。

範例：25/20 的玩家是標準 reg；45/8 的玩家是跟注站。

在名詞表查看 →
Fold to 3-bet

你開池之後面對 3-bet 棄牌的比例。

合理值 45 到 55%。高於 60% 會被對手用任何牌 3-bet 剝削；低於 40% 代表跟太多。微額族群常常超過 60%。

範例：對手 Fold to 3-bet 70%，你可以用 A5s、K9s 這類牌多 3-bet 他。

在名詞表查看 →
ATS（偷盲嘗試）

Attempt To Steal，在 CO、BTN、SB 前面都棄牌時你開池的比例。

合理值 40 到 50%。太低代表晚位置開池不夠寬，浪費了位置優勢。

範例：ATS 30% 的玩家在 BTN 只開很強的牌，可以對他的開池多尊重。

在名詞表查看 →
偷盲

在 CO、BTN 或 SB 開池，目的是讓盲位棄牌直接拿走盲注。

因為盲位常常棄牌，晚位置可以用很寬的範圍開池。偷盲是 BTN 賺錢的主要來源之一。

範例：前面都棄牌，你在 BTN 拿 J8s 加注 2.5bb，SB 和 BB 都棄牌，你贏 1.5bb。

在名詞表查看 →
Fold BB / SB to steal

你在盲位面對晚位置開池時棄牌的比例。

BB 合理值 55 到 65%，SB 80 到 85%（因為 SB 是 3-bet 或棄牌）。BB 超過 70% 就是防守不足，對手會一直偷你。

範例：對手 Fold BB to steal 80%，你在 BTN 可以用幾乎任何牌開池。

每天 20 分鐘的 Trainer 是本教材的核心訓練。目標分數依階段 85 到 90 分。可以依手牌類別練習。

§2 3-bet 構築原則

線性（linear）vs 極化（polar）

型態結構什麼時候用
線性從最強往下排，沒有「跳過的中段」對手範圍寬（BTN/CO 開池）、對手面對 3-bet 常跟注、你在 OOP（因為冷跟很差，中段牌只能 3-bet 或棄）
極化價值 ＋ 阻擋牌詐唬（A5s–A2s、K9s–K6s 等），中段牌（99–TT、AQo、KQs、JTs）去冷跟你在 IP 且冷跟是好選項（BTN vs CO、BTN vs HJ、CO vs UTG 少量）

為什麼 A5s–A2s 是標準 3-bet 詐唬

  • 阻擋 AA / AK / AQ（對手最常 4-bet 與跟注的組合）。
  • 被跟注時有可玩性（堅果同花、輪子順子、A 高有時能贏）。
  • 被 4-bet 時可以乾淨棄牌，但也是 5-bet 詐唬的候選（阻擋 AA/AK）。

阻擋牌與「不阻擋」

  • 3-bet 詐唬要阻擋對手「繼續」的範圍（A、K）。
  • 想讓對手跟注時（價值 3-bet），你希望不阻擋他的跟注範圍，所以 QQ/JJ 的價值比 AK 更「乾淨」（AK 阻擋了對手的 AQ/AJ/KQ）。

🎲舉例
CO 開池 2.5bb，你在 BTN。拿到 A♠5♠：在 3-bet 詐唬的名單裡，3-bet 到 7.5bb。拿到 9♥8♥：在冷跟名單裡，跟注 2.5bb。拿到 K♦7♣：兩個名單都不在，棄牌。拿到 QQ：3-bet 價值，7.5bb。

§4 BB 防守（最常被低估的 EV 來源）

總防守量（vs 2.5bb；抽水解）

🔎怎麼讀這張表
「總防守 45–50%」= 你在 BB 面對 BTN 的 2.5bb 開池，有將近一半的起手牌會留下來，其中大部分是跟注、一小部分是 3-bet。為什麼這麼寬：你已經放了 1bb 在底池裡，只要再付 1.5bb 就能看翻牌，賠率很好。開池的人位置越早（UTG），他的範圍越強，你防守就越窄。
開池者總防守其中冷跟其中 3-bet
UTG25–30%20–25%5%
HJ30–35%25–28%6–7%
CO38–42%30%8–9%
BTN45–50%35–38%11–13%
SB（3bb）50–55%35–40%15–17%

尺寸效應

  • vs 2bb：各加 5–8%。
  • vs 3bb：各減 5–8%。
  • vs 4bb+（魚的大開池）：只用價值＋高可玩性的牌防守，不要被「賠率好」騙去跟 K7o。

BB vs BTN 2.5bb 的防守形狀（量級）

  • 冷跟：所有口袋對、A2s+、K5s+、Q8s+、J8s+、T8s+、97s+、86s+、75s+、65s、54s、ATo+（AJo 部分 3-bet）、KTo+、QTo+、JTo。
  • 3-bet：QQ+、AK、AQs（部分）、A5s–A2s、K9s–K8s 部分、少量 T9s/98s、AJo/KQo 部分。
  • 棄牌：K4o 類、Q7o 類、J6o、T6o、小的不同花斷張。

為什麼 BB 要防守這麼寬

你已經投入 1bb，面對 2.5bb 只需再付 1.5bb 贏 4bb（底池 2.5 + 0.5 + 1）→ 需要約 27% 的原始權益，而且你會 realize 其中一部分；加上抽水與 OOP 的 realize 懲罰，所以防守線大約落在「翻後能實現權益的牌」。

§5 面對 3-bet（你是開池者）

決策比例（量級，vs 標準 3-bet 尺寸）

4-bet 範圍的結構

  • 價值：QQ+、AK。對很緊的 3-bettor（3-bet < 5%）：KK+ 為價值、QQ 與 AK 改跟注。
  • 詐唬：A5s–A2s 為主，部分 AJo / KQo / A9s–A8s（阻擋牌，且被跟注時能做頂對）。
  • 比例：100bb 下 4-bet 價值：詐唬 ≈ 55:45 到 60:40。
🎲舉例
你在 BTN 開池 2.5bb，SB 3-bet 到 10bb。你拿 AA：4-bet 到 23bb（價值）。拿 A♠5♠：大多數時候 4-bet 到 23bb 當詐唬，被 5-bet 全壓就棄。拿 99：跟注 10bb，翻後靠位置打。拿 K♣J♦：棄牌，這種牌被 3-bet 之後很容易被支配。

跟注 3-bet 的範圍

  • IP（BTN/CO 面對盲位 3-bet）：99–JJ、QQ 部分、AQ、AJs、KQs、ATs、KJs、QJs、JTs、T9s、少量 98s/87s。
  • OOP（HJ/CO 面對 BTN 3-bet）：縮到 TT–JJ、AQs、AKo 部分（部分 4-bet）、KQs；不同花高張幾乎全棄。
  • 關鍵：OOP 跟 3-bet 的牌需要「翻後能做頂對或更好」，AJo/KQo OOP 跟 3-bet 是 NL25 最常見的翻前漏洞之一。

§6 面對 4-bet（你是 3-bettor）與 5-bet

情況動作
面對 4-bet，你 IP（BTN 3-bet vs CO 4-bet）5-bet all-in：KK+、AK；跟注：QQ、JJ、AQs、AKo 部分（SPR ≈ 1.5，翻後可玩）；A5s–A4s 部分 5-bet 詐唬
面對 4-bet，你 OOP（SB/BB 3-bet vs BTN 4-bet）5-bet all-in：KK+、AK、QQ（vs 寬 4-bettor）；跟注：QQ/JJ/AQs 少量；其他棄牌
5-bet 詐唬A5s / A4s 只在對手 4-bet 範圍含詐唬（fold to 5-bet > 50%）時使用；NL25 族群 4-bet 很少詐唬，所以 5-bet 詐唬預設不做

NL25 剝削：族群 4-bet 幾乎純價值（KK+/AK，有些人只有 KK+）。面對 4-bet 時，AQ、JJ、TT 直接棄；QQ vs 緊的 4-bettor 可以棄 OOP。

§7 Squeeze

情境範圍（量級）尺寸
SB/BB vs CO 開 ＋ BTN 跟7–9%：TT+、AQs+、AKo、A5s–A4s、KQs 部分12.5bb（4× ＋ 1×）
BTN vs UTG/HJ 開 ＋ CO 跟6–8%：JJ+、AQs+、AKo、A5s、部分 KQs10bb（3× ＋ 1×）
面對 squeeze（你是開池者）比面對單一 3-bet 更緊：4-bet QQ+/AK；跟注 TT–JJ、AQs、KQs IP
面對 squeeze（你是冷跟者）幾乎只跟注有 set/同花價值的牌，QQ+ 可 4-bet

Squeeze 的理由：底池更大、兩個對手都有「範圍被封頂」的跡象（開池者沒 3-bet 範圍以外的牌、冷跟者沒有 QQ+）。

Over-limp（跟 limp）

預設不做。例外：BTN 多人 limp 底池用小對/小同花連牌；SB 完整補盲（多人、對手翻後很弱）。

冷跟原則（IP）

  1. 你在 IP（BTN、或 CO vs UTG/HJ）。
  2. 牌有可玩性：口袋對、同花連牌、同花高張；不同花高張（KJo、QJo）很少冷跟。
  3. 後面沒有愛 squeeze 的人。
  4. 對手翻後打得比你差或範圍很寬。

OOP 冷跟（SB）在有抽水的 100bb 幾乎是 0；BB 冷跟是因為已投入 1bb 且是最後行動。

§10 抽水調整（原理，用來判斷方向）

  • 抽水在翻後底池抽，且有上限；小底池被抽的比例最高。所以「邊緣跟注看翻牌」的 EV 跌最多。
  • 3-bet 讓對手棄牌時底池不被抽（多數平台 no flop no drop）→ 3-bet 相對冷跟更好。
  • 具體方向：
    • BB 總防守 減 3–5%。
    • SB 冷跟 ≈ 0。
    • 小對/小同花連牌的冷跟減少（implied odds 被抽水吃掉）。
    • UTG/HJ 開池稍緊；BTN 開池變化不大。
  • 返水等於抽水減少：返水 30% 以上時可以把 BB 防守放寬回去 2–3%。

§11 常見翻前錯誤 Top 12（每週自檢）

  1. SB 冷跟開池。
  2. BB 面對 BTN 2.5bb 棄 K9s / Q9s / J9s / T8s / 98s 類。
  3. 3-bet 全線性、沒有阻擋牌詐唬（對手面對你的 3-bet 永遠不會錯）。
  4. OOP 3-bet 尺寸太小（對手 IP 跟注太爽）。
  5. OOP 跟 3-bet 用 AJo / KQo / KJs。
  6. 4-bet 只有 KK+（對手的 3-bet 詐唬零風險）。
  7. 面對 4-bet 跟 AQ / JJ OOP。
  8. Squeeze 尺寸太小（給兩個人好賠率）。
  9. Iso-raise 尺寸太小、範圍太寬（對魚 iso 要價值導向）。
  10. UTG 開池太寬（ATo、KJo、Q9s）。
  11. 對短碼（40bb）用 100bb 範圍（短碼的 3-bet 幾乎都是全壓，應該用更緊的跟注＋更多直接棄）。
  12. 多人 limp 底池 over-limp 太多，翻後 OOP 打不出 EV。

§12 從 GTO Wizard 建立你自己的翻前總表

  1. Cash → 6-max → 100bb → 抽水結構選最接近你平台的（有 NL25 就選 NL25）→ 開池尺寸選你實際用的 → Simple。
  2. 依序開：RFI → vs RFI（每個位置組合）→ vs 3-bet → vs 4-bet → squeeze → 存進 Range Builder 或截圖。
  3. 混合頻率的處理規則：
    • 動作頻率 ≥ 70% → 當 100% 做。
    • 30–70% → 由對手類型決定：對緊/愛棄的多 3-bet 詐唬；對鬆/愛跟的多價值、少詐唬。
    • < 30% → 當 0%。
  4. 做成一頁總表貼在螢幕旁，兩週內脫離它。
